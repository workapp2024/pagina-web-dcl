# Recursos de marcas de pago

La interfaz permite guardar un nombre y una URL HTTPS para cada marca. Una URL vacía deja el nombre como alternativa. La selección de una marca es únicamente una indicación de aceptación comercial y no habilita ni altera el checkout. Antes de activarla, ADMIN debe verificar que DCL acepte esa marca en la cuenta/proveedor que procesa tarjetas.

No se distribuyen archivos gráficos de marca en el código. Los recursos oficiales consultados ofrecen lineamientos o activos sujetos a sus propios requisitos; que un archivo esté publicado no confirma por sí solo que DCL tenga autorización para usarlo.

| Marca | Recurso oficial localizado | Pendiente para DCL |
| --- | --- | --- |
| Mercado Pago | [Descarga oficial de logo](https://www.mercadopago.com.ar/mp/logo-oficial), con variantes y guía de aplicación. | Descargar la variante adecuada y cargarla en ADMIN solo si se muestra Mercado Pago como medio realmente habilitado. |
| Visa | [Visa Brand Guidelines](https://merchantsignage.visa.com/brandguidelines) ofrece logos de aceptación y reglas de uso para comercios. | Confirmar aceptación Visa por el proveedor y usar el activo/variante de comercio aplicable. |
| Mastercard | [Mastercard Brand Center](https://brand.mastercard.com/brandcenter-es/artwork.html) ofrece artwork y lineamientos oficiales. | Obtener el activo autorizado para DCL y confirmar aceptación Mastercard por el proveedor. |
| American Express | [Material digital para comercios](https://www.americanexpress.com/it/merchant/materiale-puntovendita/materialidigitali.html) incluye logo web y términos de licencia en ese mercado. | Solicitar/obtener el paquete y términos aplicables a DCL en Argentina; no se reutiliza automáticamente el paquete regional. |
| Naranja X | No se encontró una descarga pública oficial de marca de aceptación para comercios con términos claros de uso. | Solicitar a Naranja X o al adquirente el logo y permiso/guía aplicables, y confirmar que el medio se acepte en checkout. |
| Cabal | El [sitio oficial de Cabal](https://cabal.com.ar/personas/cabal-movil) muestra su marca y dirige a adhesión de comercios; no se encontró un paquete público de aceptación web con licencia. | Solicitar a Cabal/PRISMA el activo de aceptación para comercio y confirmar habilitación de DCL. |

Para cuidar el rendimiento, usar un SVG autorizado y liviano o un PNG/WebP comprimido de dimensiones pequeñas. Las imágenes se cargan con `loading="lazy"`, dimensiones reservadas y tamaño visual limitado; se alojan donde DCL tenga autorización y control de caché.
